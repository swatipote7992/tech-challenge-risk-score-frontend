# Risk API

## Installation

`npm install`
(Should work on any version of node >= 18.15.0)

## Running the server

`npm start`
`npm run start:dev` (for watching code changes)


## Testing
Unit tests (at a file level) can be run with
`npm test`

E2E tests (at an end point level) can be run with:
`npm run test:e2e`

(see package.json for some other useful test commands)
